Accounts

One username:password per line. Names must be 3–16 characters of [A-Za-z0-9_] — AuthMe disconnects shorter names at join and Minecraft caps the length. Generate fills the box but does not save; save when you are happy with it.

Party

Formation is automatic while the fleet joins: the first bot in invites each other bot as it arrives. Use Invite all to redo it by hand.

Members

Kick removes one member from the party. The leader does the kicking.

Master

The master is a real player, not one of the bots. Invite them, then hand over leadership. Form party with master does the whole sequence in one go.

ms

Menu

Drives a chest-style GUI: select a hotbar slot, right-click to open the menu, then click a slot inside it. Row and column are counted from 1, the way you count them on screen. This uses real mouse clicks, not number keys.

Sneak bridge

Holds sneak, walks in the chosen direction, and places a block into the gap ahead of each step. Sneak is released when the bot can no longer move — the bridge is done. Needs blocks in the inventory.

Server actions

Warp uses your server's own warp plugin, so edit the command on the Commands tab if /warp is not what yours uses.

Command config

Type the real server command. {player} is the target, {message} the body, {warp} the warp name. Press Learn to make a bot send it and read the reply back.
